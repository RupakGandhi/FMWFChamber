**Published side-by-side benchmark:** [https://fmwfapps-j4ebl3f4.manus.space](https://fmwfapps-j4ebl3f4.manus.space)

The production platform uses native Chamber-managed administrator accounts. Create the first administrator with `scripts/create-native-admin.mjs`; do not substitute staff OAuth. Reviewers and applicants remain account-free.

Verify the external SHA-256 checksum before installing or deploying this package.
